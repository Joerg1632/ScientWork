# Simulation of Machine Failure and Recovery

Проект реализует статистическое моделирование систем массового обслуживания с отказами и восстановлениями оборудования. Основная цель — сравнение различных вероятностных распределений времени жизни и восстановления машин, а также сопоставление результатов симуляции с аналитическими решениями.

## Описание задачи

Рассматривается система из `N` машин. Каждая машина может находиться в одном из двух состояний: **работает** или **в отказе**. Время до отказа и время восстановления задаются вероятностными распределениями. Моделируется эволюция числа работающих машин `N(t)` во времени.

По результатам большого числа независимых экспериментов вычисляются:
- выборочное среднее `M(t)`
- выборочная дисперсия `D(t)`

## Реализованные распределения

### Экспоненциальное
Классическая модель без памяти. Вероятность отказа на шаге не зависит от того, сколько машина уже проработала. Для этого распределения существует аналитическое решение, которое используется для верификации симуляции.

### Вейбулла
Распределение с памятью, задаётся параметрами формы `δ` и интенсивности `λ`. При `δ < 1` — режим приработки (ранние отказы), при `δ > 1` — износ. Параметры подбираются так, чтобы среднее время жизни совпадало с экспоненциальной моделью, что обеспечивает корректное сравнение графиков.

### Логнормальное
Распределение с памятью, задаётся параметрами `μ` и `σ`. Параметры подбираются из условия равенства среднего и близости коэффициента вариации к модели Вейбулла.

## Алгоритм симуляции

Используется **пошаговый алгоритм с возрастом** (`step-by-step with age tracking`). Для каждой машины хранится её возраст — время, прошедшее с момента последней смены состояния. На каждом шаге `Δt` для каждой машины вычисляется условная вероятность события через точную формулу:

$$P = \frac{F(\tau + \Delta t) - F(\tau)}{1 - F(\tau)}$$

где `F` — функция распределения, `τ` — текущий возраст машины. Это обеспечивает математически корректный учёт памяти распределения при любом шаге `Δt`.

## Структура проекта

```
SimOfMachFailure/
├── config/
│   ├── configExp.txt          # параметры для экспоненциального распределения
│   ├── configWeibull.txt      # параметры для распределения Вейбулла
│   └── configLognormal.txt    # параметры для логнормального распределения
├── results/
│   ├── resultOfManyExperiments.csv   # результаты экспоненциальной модели
│   ├── resultWeibullAged.csv         # результаты модели Вейбулла
│   └── resultLognormalAged.csv       # результаты логнормальной модели
└── src/
    ├── main_exponential.cpp   # экспоненциальное распределение + аналитика
    ├── main_weibull.cpp       # распределение Вейбулла
    └── main_lognormal.cpp     # логнормальное распределение
```

## Формат конфигурационного файла

### Экспоненциальное (`configExp.txt`)
```
0.001      # lambda       — интенсивность отказов
10000      # initial_N    — начальное число машин
0.001      # delta_t      — шаг моделирования (сек)
150        # T            — число шагов (×1000)
100        # num_experiments
1          # nu           — интенсивность восстановлений
```

### Вейбулла (`configWeibull.txt`)
```
0.73       # delta_shape      — параметр формы
0.001281   # lambda_failure   — интенсивность отказов
1.2807     # lambda_recovery  — интенсивность восстановлений
10000      # initial_N
0.001      # delta_t
150        # T
100        # num_experiments
```

### Логнормальное (`configLognormal.txt`)
```
6.4078     # mu_failure
1.0        # sigma_failure
-0.5       # mu_recovery
1.0        # sigma_recovery
10000      # initial_N
0.001      # delta_t
150        # T
100        # num_experiments
```

## Сборка и запуск

Требования: компилятор C++17 (MSVC или GCC), стандартная библиотека STL.

```bash
# GCC
g++ -O2 -std=c++17 src/main_weibull.cpp -o sim_weibull

# MSVC
cl /O2 /std:c++17 src/main_weibull.cpp
```

Результаты сохраняются в папку `results/` в формате CSV с UTF-8 BOM для корректного открытия в Excel.

## Сравнение моделей

Все три модели настроены с одинаковым математическим ожиданием времени жизни и восстановления, что позволяет напрямую сравнивать их поведение на одном графике. Экспоненциальная модель служит базовой линией с известным аналитическим решением.
